# EduERP Teacher Panel

Teacher panel for EduERP School Management System.

## Login

Teacher accounts are created by the School Admin from the real backend. There is no mock/demo login in the application.

Seed/development teacher credential from the backend seed script:

- Email: `teacher@school.edu`
- Password: `Teacher@12345`

Use a teacher account created for your school for production use.

## Environment

Create a single `.env` file:

```env
VITE_API_URL=https://erp-backend-6a3c.onrender.com/api
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
